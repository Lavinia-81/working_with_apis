# Working With APIs
A collection of Python exercises and experiments created during my early learning phase with APIs.
This project demonstrates how API requests work, how data is fetched and processed, and how Python interacts with external services.

---

## What This Project Covers
```
Making HTTP requests
Working with public APIs
Parsing JSON responses
Handling errors and invalid responses
Understanding API endpoints
Basic data extraction and transformation
Using Python libraries for API communication
```
---

## Project Structure
```
working_with_apis/
│
├── api_examples.py        # Core API request examples
├── weather_api.py         # Example: fetching weather data
├── crypto_api.py          # Example: fetching cryptocurrency prices
├── rest_api_basics.py     # Intro exercises for REST concepts
├── requirements.txt       # Dependencies (if applicable)
└── README.md              # Documentation
```
Structure may vary depending on your exercises, but the README remains valid.

## How to Run
Clone the repository:
```
bash
git clone https://github.com/Lavinia-81/working_with_apis
Navigate to the project:

bash
cd working_with_apis
Install dependencies (if requirements.txt exists):

bash
pip install -r requirements.txt
Run any example:

bash
python api_examples.py
```
